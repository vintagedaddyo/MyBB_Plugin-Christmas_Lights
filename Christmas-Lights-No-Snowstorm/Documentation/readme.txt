This plugin allows you to display Christmas lights at the top of your forum. You can even smash them by hovering over them.

Contains a fix to allow you to click links behind the lights.

Also has a setting for toggling smashable lights, sometimes we just don't want things broken right? =]

This is a MyBB plugin for the script created by Scott Schiller
http://www.schillmania.com/projects/snowstorm/lights/


Updated to version 1.2 for MyBB 1.8.x usage by Vintagedaddyo
- minor changes to code
- no longer linking to external css and js files
- smashable sounds now work again
- added localization

To Install:

Upload The Files, And Go to Admin CP And Active IT!
